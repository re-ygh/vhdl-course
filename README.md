# VHDL Coursework | پروژه‌های VHDL

Selected VHDL projects from university coursework. Each project is kept in a separate folder with its source, required project files, and a README.

پروژه‌های منتخب درس VHDL/CAD دانشگاه، با پوشه و راهنمای جدا برای هر پروژه.

| Folder | Description | Tool context |
| --- | --- | --- |
| [register-file](register-file/) | 16-entry, 16-bit register array with operations and a self-checking testbench | Active-HDL / VHDL-93 |
| [butterflyscape](butterflyscape/) | FPGA game with VGA output and board pin constraints | Xilinx ISE 14.7 / Spartan-6 |

Generated simulation waveforms, synthesis outputs, logs, and the original archive are omitted. The source files are preserved from the university projects. Simulation and synthesis have not been rerun in this prepared copy.
